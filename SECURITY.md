# Security

LifeHarness keeps your life map, plans and AI sign-ins on your computer, so security problems matter.

## Reporting a problem

**Please don't report security problems in public issues.** Report them privately through GitHub: on this repository, open **Security → Report a vulnerability** ([direct link](https://github.com/eOvic/LifeHarness/security/advisories/new)).

Include what you found, how to reproduce it, and which version and system you used. You'll get an answer as soon as possible. Once a fix is released, you'll be credited if you want to be.

## Supported versions

Only the [latest release](https://github.com/eOvic/LifeHarness/releases/latest) gets security fixes. Update to it before reporting.

## What's in scope

Examples: another program or website reaching LifeHarness's local server; your sign-ins, API keys or life data leaking out of the app's private folder; the AI or a web page making the app do something you didn't ask for.
